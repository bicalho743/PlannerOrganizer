✅ Possíveis causas e soluções
1. Uso incorreto da biblioteca
Você pode estar tentando usar um método que não existe na biblioteca que está utilizando. Verifique qual biblioteca você está usando para autenticação com Firebase. Por exemplo:

Se estiver usando firebase_admin, ela não oferece métodos prontos para login com Google — ela é usada principalmente para operações administrativas (como verificar tokens, acessar o Firestore, etc.).

Se estiver usando pyrebase4, a autenticação com Google precisa ser feita manualmente no frontend, e você só verifica o token no backend.

➡ Solução: não tente gerar a URL pelo backend. O fluxo de login com Google deve ser iniciado pelo frontend (com JavaScript ou SDK do Firebase Web), e depois o backend pode validar o ID token recebido.

2. Está esperando funcionalidade de outra biblioteca
Talvez você tenha seguido algum exemplo baseado em outra biblioteca, como authlib, flask_dance, ou até algum SDK de frontend, e esteja tentando usar o mesmo método no FirebaseAuth, que não suporta isso nativamente.

➡ Solução alternativa: Use o login social do Google com o SDK do Firebase Web:

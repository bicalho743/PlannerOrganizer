Problema:
No preview/local, o botão de reabrir a barra lateral aparece normalmente depois que colapso a barra.
Após o deploy, o botão não aparece — mesmo limpando localStorage ou recarregando a página.
Acredito que o botão está sendo ocultado por CSS (display: none ou visibility: hidden) ou ficando fora da tela devido a diferenças de estilo na versão de produção.

Possível causa técnica:

Regra de CSS ou media query diferente no build de produção;

position: absolute ou fixed mal calculado, fazendo o botão ficar fora da viewport;

Algum script removendo o botão do DOM quando a barra está colapsada;

z-index muito baixo, ficando atrás de outro elemento.

O que preciso:
Quero que o botão de reabrir a barra lateral:

Sempre seja renderizado no HTML, mesmo quando a barra está expandida.

Apenas altere visibilidade/posição, mas nunca desapareça totalmente após o colapso.

Sugestão de correção (exemplo CSS/JS):

/* Garante que o botão fique sempre visível e acima de outros elementos */
.sidebar-toggle {
  position: fixed; /* ou absolute, dependendo do layout */
  top: 15px;
  left: 15px;
  z-index: 9999;
  display: block !important;
  cursor: pointer;
}

/* Em telas menores, ajusta a posição */
@media (max-width: 768px) {
  .sidebar-toggle {
    top: 10px;
    left: 10px;
  }
}

// Garante que o botão reapareça sempre que a barra estiver colapsada
function showSidebarToggle() {
  const toggleBtn = document.querySelector('.sidebar-toggle');
  if (toggleBtn) {
    toggleBtn.style.display = 'block';
  }
}

// Observa mudanças no DOM para reativar o botão se sumir
const observer = new MutationObserver(() => showSidebarToggle());
observer.observe(document.body, { childList: true, subtree: true });

// Força o botão a aparecer no carregamento
document.addEventListener('DOMContentLoaded', showSidebarToggle);


Resumo:
Quero que revisem o CSS e JS no build de produção para garantir que .sidebar-toggle (ou o seletor equivalente) não seja ocultado ou posicionado fora da tela. No preview funciona, no deploy não.
